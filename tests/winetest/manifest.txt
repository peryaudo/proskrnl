# The winetest gate's manifest (tests/run/run.sh winetest): the FULL non-GUI
# sweep of Wine's own test suite — every subtest of ntdll, kernel32,
# programs/cmd, msvcrt and ucrtbase, run under the pinned Wine oracle AND on
# proskrnl from ONE binary per module (Makefile `wtests`, the pinned tree's
# own unmodified test objects linked standalone).
#
# advapi32 is deliberately out: its subject is the security/registry service
# surface, covered by the CUI-2/CUI-3 legs (tests/run/run.sh console, scm) and
# by tests/ntapi, not by this gate. user32 is out too — the GUI trophy has its
# own manifest (manifest-gui.txt, tests/run/run.sh guiwtest).
#
# COVERAGE, NOT CURATION. This file used to list only the pairs already green
# on both runners; it now lists every pair the five modules have, so the leg
# measures the whole non-GUI frontier instead of the part already crossed. A
# red pair here is a finding to work through, not a merge blocker to route
# around — the parked-pair causes that used to live in these comments are in
# docs/03 "M10 winetest notes".
#
# <exe>:<subtest>[:<timeout_s>] — the third field is the per-pair timeout
# (user/smss/session.c SessionParseWtestManifest); absent means 300 s.
